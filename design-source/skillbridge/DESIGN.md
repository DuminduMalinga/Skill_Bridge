## Brand & Style

The design system embodies a calm, focused, and intellectually empowering atmosphere. Positioned at the intersection of university academia and modern industry, the visual language merges the structured clarity of editorial productivity tools with the refined professionalism of modern career acceleration platforms. 

The aesthetic is characterized by:
- **Clean Modern SaaS with Editorial Restraint:** Generous negative space, clean typographic hierarchy, and purposeful layout structures that prevent cognitive overload for students navigating complex career roadmaps.
- **Subtle Layering over Harsh Containment:** Surface elevation and tonal shifts define visual architecture rather than heavy dividing lines or borders.
- **Empowering Calm:** High-signal, low-noise interfaces designed to reduce early-career anxiety and inspire structured progress toward market-ready competencies.

## Colors

The palette uses high-clarity neutrals paired with an intentional chromatic hierarchy to signify focus, readiness, and skill momentum.

- **Primary (`#4F46E5`):** Deep Indigo commands the core interactive layer—primary call-to-actions, active navigation states, primary focus rings, and milestone progress fills.
- **Secondary / Surface Accent (`#EEF2FF`):** Soft Indigo Wash creates low-friction contextual highlights, active list row backgrounds, and subtle tinting behind high-priority cards.
- **Tertiary / Success Match (`#10B981`):** Emerald Green indicates verified qualifications, high match percentages, and fulfilled course competencies. Accompanied by `#ECFDF5` for badge and metric surface fills.
- **Warning / Skill Gap (`#F59E0B`):** Amber provides high-visibility signaling for skill deficits, prerequisite requirements, and critical focus areas. Paired with `#FEF3C7` for containment.
- **Neutral Canvas (`#FAFAFA`):** Warm off-white creates an eye-resting base across all viewport backgrounds.
- **Surfaces (`#FFFFFF`):** Crisp pure white applied to modular cards, navigation bars, modal dialogs, and slide-overs.
- **Text Palette:**
  - Primary Titles: `#111827` (Zinc 900)
  - Secondary Subheadings & Field Labels: `#374151` (Zinc 700)
  - Body Content & Descriptions: `#4B5563` (Zinc 600)
  - Muted Metadata & Microcopy: `#9CA3AF` (Zinc 400)

## Typography

The typographic system utilizes **Plus Jakarta Sans** for headers to introduce welcoming modern geometry, while **Inter** delivers neutral, highly legible reading experiences across data sets, curriculum trees, and long-form task briefs.

- **Headlines:** Set in Plus Jakarta Sans with subtle negative letter-spacing for tight, contemporary cadence. Hero titles scale down smoothly on mobile devices to prevent awkward hyphenation or wrapping.
- **Body:** Set in Inter with relaxed line heights (`1.5` to `1.6`) to sustain effortless scanability across technical project descriptions and syllabus requirements.
- **Labels & Tags:** Set in medium and semibold weights of Inter, ensuring pill tags and state indicators retain legibility at small sizes (`12px` - `14px`).

## Layout & Spacing

The layout is built upon a 12-column responsive fluid grid capped at a maximum width of `1200px` (`max-w-7xl` centered) to maintain optimal reading widths on large monitors.

- **Desktop (1024px+):** 12 columns with `1.5rem` (`24px`) gutters and `2rem` (`32px`) page canvas margins. Standard cards span 4 columns (3-column grid) for courses/projects, or 6 columns for detailed skill bridge assessments.
- **Tablet (768px - 1023px):** 6-8 fluid columns, `1rem` gutters, and `1.5rem` outer canvas padding. Grids consolidate into 2 columns.
- **Mobile (<768px):** Single-column stacked layout with `1rem` canvas margin. Data cards and metrics reflow to vertical sequences or horizontally swipeable carousels for pill tag collections.
- **Rhythm Rules:** Vertical spacing between major layout sections strictly utilizes `space-xl` (`2.5rem` or `40px`). Component-internal padding uses `space-md` (`16px`) for dense elements and `space-lg` (`24px`) for primary dashboard cards.

## Elevation & Depth

Visual hierarchy avoids heavy borders, employing ambient, ultra-diffused drop shadows combined with pure white surfaces against the `#FAFAFA` neutral background.

- **Resting Surface (Level 1 - Cards & Lists):** Pure white with subtle diffuse illumination:
  - `box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.04), 0 1px 2px -1px rgba(0, 0, 0, 0.02);`
  - Subtle perimeter ring: `1px solid rgba(0, 0, 0, 0.03)` to prevent clipping on low-contrast screens.
- **Interactive / Hover Surface (Level 2 - Hovered Cards & Popovers):** Soft floating lift:
  - `box-shadow: 0 10px 15px -3px rgba(0, 0, 0, 0.05), 0 4px 6px -4px rgba(0, 0, 0, 0.02);`
  - Subtle upward translation of `-2px` with a 200ms ease-out curve.
- **Overlay Surface (Level 3 - Modals & Floating Toolbars):**
  - `box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.08), 0 8px 10px -6px rgba(0, 0, 0, 0.03);`
- **Tinted Inset Depth (Skill Meters & Progress Tracks):** Inset tracks for circular progress and linear bars use a flat `#E5E7EB` or primary tint `#EEF2FF` without inner shadows to preserve a light modern feel.

## Shapes

The design system incorporates generous curvature to project warmth, approachability, and ease of interaction:

- **Cards and Major Panels:** Standardized to `rounded-xl` (`16px` / `1rem`), providing smooth contouring that balances editorial structure with modern app design.
- **Buttons, Text Inputs, and Form Containers:** Form components use `rounded-lg` (`8px` to `12px`) for precise affordance.
- **Skill Badges, Status Pills, and Indicators:** Fully rounded (`rounded-full` / `9999px`) to create clear shape contrast against the rectangular content cards.
- **Circular Progress Rings:** Perfectly rounded SVG radial tracks featuring rounded stroke terminals (`stroke-linecap="round"`).

## Components

### Buttons
- **Primary:** Deep Indigo background (`#4F46E5`), pure white text, 10px 18px padding, `rounded-lg`, subtle transition on hover (`#4338CA`), focus ring with `3px` Indigo-200 outline.
- **Secondary:** Soft Indigo surface (`#EEF2FF`), Deep Indigo text (`#4F46E5`), zero border, hover shifts to Indigo-100 (`#E0E7FF`).
- **Ghost / Tertiary:** Transparent background, Zinc 700 text (`#374151`), hover background `#F3F4F6`.

### Chips & Pill Tags
- **Skill Match Pill:** Emerald-50 background (`#ECFDF5`), Emerald-700 text (`#047857`), `rounded-full`, 4px 10px padding, 12px font size, optional checkmark icon.
- **Skill Gap Pill:** Amber-50 background (`#FEF3C7`), Amber-700 text (`#B45309`), `rounded-full`, 4px 10px padding, 12px font size, optional alert circle indicator.
- **Neutral Skill Pill:** Zinc-100 background (`#F3F4F6`), Zinc-700 text (`#374151`), fully rounded.

### Circular Progress Rings (Readiness / Match Scores)
- Dual-path SVG dials: Base background path with `#EEF2FF` or `#E5E7EB` stroke; dynamic foreground stroke in `#4F46E5` (Overall Readiness) or `#10B981` (Role Match).
- Center text displays bold percentage with a small uppercase label beneath (`88%` / `MATCH`).

### Cards (Courses & Applied Industry Projects)
- Solid `#FFFFFF` surface, `16px` corner radius, `24px` internal padding, resting Level 1 elevation.
- Header row containing company or university affiliation badge paired with an action menu.
- Content zone with a `headline-sm` title, a two-line clamp for description, and a horizontal flex row of skill pills.
- Footer featuring a subtle top border line (`#F3F4F6`), progress indicator, and action CTA.

### Input Fields
- Flat white background, border `1px solid #E5E7EB`, `rounded-lg`, 10px 14px padding.
- Text in `#111827`, placeholder in `#9CA3AF`.
- Active focus state: Border color changes to `#4F46E5` accompanied by an ambient `0 0 0 3px rgba(79, 70, 229, 0.12)` halo.

### Checkboxes & Radio Buttons
- Custom SVG boxes (`18px × 18px`), `rounded-md` (checkbox) or `rounded-full` (radio).
- Unchecked: `1.5px solid #D1D5DB`, pure white fill.
- Checked: `#4F46E5` background fill with crisp white internal mark.

### Lists & Curriculum Trees
- Borderless rows separated by `8px` vertical spacing.
- Left-hand milestone status icon connected via a thin 2px vertical guide rail (`#E5E7EB`).
- Hover state: Entire row highlights with `#F9FAFB` and shifts right by 2px.
